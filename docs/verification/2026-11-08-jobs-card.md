# Background-task card alignment

Compared the local BB reference:
- apps/app/src/components/promptbox/banner/PromptStackCard.tsx
- packages/shared-ui/src/components/ui/chrome-style-tokens.ts
- packages/shared-ui/src/components/ui/prompt-stack-disclosure.tsx

The job panel now uses BB context-card background/border tokens, a full-width
32px minimum header (44px coarse pointer), a compact running count, shared
icons, and a bottom collapse row. Each panel has its own React-generated
aria-controls target. Escape and bottom collapse return focus to the header;
external collapse also restores focus if it was inside the body. Existing
disclosure animation and reduced-motion behavior remain shared.

Browser review used an isolated Vite fixture with the actual JobsPanel and app
CSS. At 390x844 the light screenshot and measured scrollWidth=innerWidth=390
showed no root overflow. The dark screenshot showed the selected job and bounded
body scrolling. This was component review, not a new end-to-end device test.
Screenshot file export was unavailable in the tool workspace; images were
inspected inline.

The dark fixture exposed a separate parser edge: an empty stream without the
extra blank line caused raw stdout/stderr tags. Parsing now accepts both empty
stream forms. Regression cases verify stdout-only, stderr-only and both empty,
including clipboard text. This parser correction was verified by automated
rendering tests after the fixture review.

Validation: TypeScript, all 70 web test files / 267 tests, and production build
passed. JobsPanel regression verifies Escape and bottom-collapse focus return,
alongside existing thread switching, cancellation, visibility and polling checks.
