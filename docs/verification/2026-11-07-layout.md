# 全页面基础布局检查

本地构建基于 `7f60394`，验收服务 `127.0.0.1:19240`；BB 源码参考版本 `f51e6b0`。

检查 Dashboard、Batch、Sessions、Files、Terminal、Desktop、Agent 七个路由；每页覆盖 390、768、1440px 和亮/暗两种主题，共 42 个组合。前台标签页等待布局过渡后测量，均满足根页面 scrollWidth 等于视口宽度。亮色背景为 oklch(1 0 0)，暗色为 oklch(0.195 0 0)。768px 及以上导航轨宽 48px；390px 工作区保留导航轨，管理页面使用菜单入口。

人工查看手机截图发现并修正：Sessions 提示误指“左侧”（手机列表实际在上方），Terminal 无标签页时没有下一步说明。均改为与布局无关的操作指引。

范围限制：本轮设备列表为空、Agent 未配置，不能证明真实设备、长列表、真实终端输出、桌面视频、Agent 流式会话和浮层全部通过。尺寸与主题检查也不等于所有视觉细节与 BB 完全一致。完整验收仍待上述交互状态及宽屏截图检查。

## 本地真实客户端增量检查

连接当前 Go 客户端，设备 ID 为 `visual-review-device-with-a-long-name`，只用于本地验收。390px 亮色终端实际执行 `printf` 和 `pwd`，输出正常；长标签截断且关闭、分屏入口仍可见。设备栏展开时完整设备名可通过可访问名称识别，终端区域退出可访问树，收起后恢复。Files 成功列出真实目录并显示分页计数。

文件路径切换与双窗格未判定通过：复用的浏览器上下文出现非预期路由切换，随后改用独立上下文 `rdev-nov7-acceptance`（page 17）继续复测。测试设备持续连接本地验收服务；尚未验证桌面视频和完整 Agent 命令交互。

## Files 实际数据复测与修复

独立上下文复测确认路径输入后 Enter 可正常切换到测试目录。390px 暗色截图暴露自动表格布局被长文件名撑宽，大小换行、操作区被裁切；改为固定表格布局，大小/操作列保留宽度，文件名在剩余空间截断，窄窗格下载操作使用有可访问名称的图标。重新构建服务后同一真实文件列表截图确认三列完整、大小单行、下载和更多入口可见。118 项 Web 测试、TypeScript 和生产构建通过。双窗格与视频/Agent 全链路仍待继续。

## 双窗格与后台命令链路

Files 实测 390px 暗色为上下双窗格，1440px 亮色为左右双窗格（设备栏 312px、导航轨 48px，两窗格约 540px）。测试未涉及实际跨窗格复制。

独立 Agent 验收服务使用本地 SSE 固定回复模型和真实 Go 设备客户端。输入 `/bg sleep 15; printf 'background verified\\n'` 后直接出现 bg 审批卡；允许后显示后台任务运行中，15 秒后任务状态为 completed、退出码 0、输出 `background verified`，并触发后续模型回复。该证据证明命令、审批、真实执行、任务完成通知链路；不证明任意模型质量或 subagent/compact 已完成端到端验收。

发现待修问题：内部后台任务完成通知作为用户消息展示整段英文指令和 JSON，应改为简洁的任务完成卡片，同时保留模型收到完整工具数据的行为。浏览器原生按键测试偶发失焦触发导航，本轮命令提交使用输入框 keydown 事件，键盘焦点链路仍需单独复测。
