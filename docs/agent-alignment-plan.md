# Agent 与 BB 后续优化范围

以下六项均属于已授权范围；逐项验证并提交，不以局部修复代替整体完成。

- 多会话状态：成功/失败/取消、刷新后未读恢复、断线期间更新和分屏已读语义。
- 键盘焦点：原生 Enter、IME、命令菜单、弹窗关闭、设备切换，定位浏览器验收中的意外导航。
- 任务通知：服务端结构化事件与持久历史；保留旧通知兼容，避免依赖文本前缀作为长期协议。
- BB 真实状态验收：亮暗色、三个宽度、长列表/输出、审批/分屏/浮层、真实桌面视频。
- 压缩交互：圆环详情中的压缩入口、进度、失败恢复及结果反馈；底部不显示 token 数字。
- 后台结果：统一状态、耗时、复制、输出跟随与手动滚动位置保留。

当前进度：未读与已观察运行状态已支持标签页刷新恢复；结构化任务通知、压缩反馈、后台耗时/复制、消息导航、图片预览和画布已接通。

当前限制：前台轮次结果与后台任务结果需要区分，不能把模型回复成功当作所有工具或任务成功。最近前台轮次结果已持久化；服务端重启后，未完成的 running 标记恢复为 stopped，避免沿用上一轮成功状态。
