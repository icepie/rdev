# UI 风格与响应式约定

以 BB 的工作区布局和语义主题为基准。所有页面复用 `web/ui/styles/app.css` 与 `web/ui/components`，避免页面自行复制主题值和控件样式。

## 布局

- 应用导航由 AppShell 管理；Agent 保持 48px 导航轨和默认 312px 会话栏。窄屏侧栏宽度为 `min(100vw - 48px, 312px)`，聊天区随侧栏平移。
- Dashboard、Batch 使用 `page-content`：最大宽度 80rem，移动端 12px、较宽屏 16px 内边距，区块间距 16px。
- Files 使用满屏工作区，路径与操作固定在顶部，列表独立滚动。任务面板按需展开；以窗格宽度 800px 为界，宽窗格放右侧，窄窗格放底部，避免分屏时拥挤。
- 文件、终端、桌面与 Agent 均保留 48px 导航轨；设备栏默认 312px，可拖动调整，移动端采用揭开式布局。设备搜索与分组折叠不卸载工作区。
- 桌面设置通过“画面与控制”按钮展开，默认将空间留给画布；终端标签栏统一 48px，保留分屏与后台连接。
- Agent 侧栏把设备图标、在线状态和会话数放在分组头，组内会话缩进；运行状态不与操作按钮重叠，搜索时展开命中的分组。
- Terminal、Desktop、Sessions 使用 `page-workspace`：填满父容器，并允许内部区域收缩、独立滚动。Agent 使用相同主题和组件，保留专门的分屏、侧栏和输入区布局。
- `page-toolbar` 统一工具栏分隔线、背景、8px 控件间距、12px 水平内边距和至少 44px 行高；内容过多时允许换行。
- `page-title` 用于页面标题；`page-empty-card` 用于居中的连接提示卡片。
- 不在页面根节点制造横向滚动。表格、代码、终端等有固有宽度的内容在自己的区域滚动。

## 视觉与组件

- 颜色使用语义 token：`background/card/sidebar`、`foreground/muted-foreground`、`border/border-seam`、`success/warning/destructive`。浅色和深色主题共用组件，不写页面专属灰色或透明度补丁。
- 字体沿用 Inter；普通小字号为 13px，正文 15px，页面标题用 `text-lg font-semibold`，卡片标题 `text-sm font-semibold`。等宽字体只用于代码、路径和终端内容。
- Card 默认圆角 8px、细边框、16px 内边距；不增加页面专属大阴影。
- 操作优先使用 Button；表单复用 Input、Textarea、Select、Label、Switch；浮层复用 Dialog/ResponsiveOverlay。保留这些组件的 focus、disabled、键盘和触屏规则。
- 工具栏次要操作用 ghost/outline；危险操作用 destructive。纯图标操作提供可读的 aria-label。
- 侧栏和紧凑工具区统一以 768px 为断点。触屏下普通 Button 与表单输入为 40px 高；页头紧凑图标按钮沿用 36px 专用规格。不要用固定高度挤压多行文本或移动端表单。

## 验证

涉及布局修改时检查 390px、768px、1440px 宽度，浅色/深色主题、长设备名、空列表和打开的浮层；Agent 额外检查侧栏开关、分屏及软键盘 visual viewport。终端画布和远程桌面图像保持各自的尺寸适配逻辑。

2026-11-06 本地浏览器回归：Files、Desktop、Terminal 的空设备状态在上述三个宽度和亮/暗主题下共 18 个组合均无页面横向溢出；宽屏侧栏为 312px、内容起点为 360px。390px 手机截图确认设备栏展开后工作区 inert，文件任务面板落在底部。该检查不包含真实设备、长设备名、视频流或终端输出；这些状态仍需单独验证。测量前将被测标签置于前台并等待动画完成，避免浏览器后台渲染节流导致中间态读数。

## BB 主题来源

`bb-theme.css` 的默认亮/暗主题变量、`bb-code-highlight.css` 的语法色和五个配色预设直接移植自 BB `f51e6b0`。保留原 MIT 许可于 `docs/licenses/bb.txt`。默认 BB 配色不叠加 RDev 专属灰阶；亮暗模式与配色预设独立选择。系统模式跟随浏览器配色偏好，多个标签页同步主题选择。

代码围栏（包括无语言的单行围栏）、工具 JSON、文件读取结果使用 BB 的 sugar-high 语言别名与有界缓存。diff/文件预览沿用 Pierre，并通过 BB 的 `--diffs-*` 变量跟随页面背景与增删色。

命令输出的 ANSI 16 色使用相同的 `--ansi-*` 主题变量，切换配色即时生效；shell 命令头使用共享语法高亮。xterm 通过 sRGB canvas 把浏览器的 oklch/color-mix 颜色转换为兼容的 RGBA，终端页和 Agent 终端共用转换逻辑。

设备侧栏与 Agent 共用 `workspace-sidebar.ts` 的 312px 默认宽度、240–460px 调整范围和行样式。设备侧栏宽度按像素保存，不随窗口百分比漂移；分隔线支持方向键、Home/End 和双击复位。设备高亮来自工作区实际选择，终端来自聚焦标签。侧栏展开、折叠及断点切换不卸载工作区；窄屏保持揭开式动画，支持 Escape 与外侧点击关闭。

窄屏展开设备栏时焦点移入侧栏，关闭后返回触发控件；断点切换隐藏侧栏或缩放手柄时，将其中的焦点移回工作区，不能让键盘焦点留在 inert 或不可见区域。已输入的内容及活跃连接不因焦点移动重新挂载。

文件任务面板始终保留挂载，通过网格行/列过渡在底部或右侧展开；桌面设置使用 `DisclosureBody` 并保留控件挂载，收起后不可聚焦，重新展开保持设置状态。

Agent 的思考、工具详情、工具分组和待办列表共用 `DisclosureBody`：采用 BB disclosure 的 200ms ease-out 网格高度/透明度过渡。内容首次展开才挂载，之后折叠保留局部状态；隐藏内容设置 inert/aria-hidden 并暂停后代动画。流式文本更新不改变开合状态，因此不会反复触发入场动画。减少动态效果模式通过全局规则关闭过渡。

## 文件复制的目录语义

跨设备复制会先在目标设备创建目录并等待确认，再调度该目录内的文件，保留空目录。目录已存在时允许合并；同名普通文件或权限错误会中止当前递归并提示错误。已经开始的文件任务仍独立显示进度，不把整个递归标记为成功。目录请求按 requestId 隔离，断线立即结束等待，30 秒无回复提示超时；目标设备须使用支持 `file_mkdir` 的新版客户端。

2026-11-06 自动验证覆盖：Go/Rust 客户端在临时目录中创建嵌套空目录、重复创建及普通文件冲突；前端验证先建目录后递归，以及成功、失败、超时、断线回包，并覆盖受密码保护的设备。尚未完成真实远端设备联调。

文件页提供两个独立浏览窗格，侧栏选择设备作用于当前窗格。内容宽度达到 900px 时并排，否则上下堆叠；“收起第二窗格”保留该窗格的连接、路径和任务。第一窗格继续独占 URL 设备参数与原任务持久化。复制菜单禁用尚未选择设备的目标。

2026-11-06 双窗格验证：组件测试实际挂载两个浏览器，验证设备路由、跨窗格空目录复制、收起/展开不重连及路径保留；浏览器在 390/768/1440px 和亮/暗模式下共六个空设备组合无页面横向溢出，窄屏上下排列、宽屏并排。截图检查还发现并修正分屏按钮的图标名称。上述视觉检查未覆盖真实设备内容。
