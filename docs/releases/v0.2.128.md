# v0.2.128

本版集中更新 Agent、浏览器联动、跨客户端桌面操作和统一界面体验。

- Agent 原生按需截图覆盖 Go Windows/macOS/Linux 的已有桌面后端、Rust GPU 和 Android；复用捕获会话，键鼠操作不再额外截图，服务端无需 FFmpeg。
- 新增设备路由的浏览器/桌面工具，服务端 Chrome 可使用所选设备的网络；改善侧栏联动、输入法输入和 DevTools 默认展示。
- 移植 OMP 18.18.3 的部分循环与供应商完成处理逻辑，取消默认 25 轮硬限制，完善内容过滤、流结束、后台任务与会话隔离处理。
- 改善会话置顶、离线历史访问、队列编辑、图片与工具输出展示，以及 BB 风格的移动端布局和各页面导航。
- 修复发布冒烟测试认证和 macOS runner 配置。

升级说明：服务端与客户端建议一起更新。旧 Go 客户端保留桌面协议回退；旧 GPU/Android 客户端使用新原生截图接口前需要升级。原有系统捕获/无障碍授权要求不变。Android 截图复用投屏授权，已有视频可能短暂停帧后恢复。

验证：Go race 测试、Rust 客户端及像素转换测试、Android 单元测试/APK 构建、桌面面板复用测试通过；Windows 和 macOS 无 CGO 客户端交叉编译通过。全部物理设备及原生后端尚未完成实机验收。

发布限制：仓库未配置更新包签名密钥，本版无签名的资产仅供手动安装；启用签名校验的客户端自动更新会拒绝无签名包。Android 资产按现有流程提供 debug APK。
