# v0.2.147

本版恢复一键安装脚本的低依赖兼容性。

- Windows `run.ps1` 与 POSIX `run.sh` 移除 OpenSSL 前置要求、Ed25519 验签器和 `.sig` 下载；无需安装额外验签工具。
- 缓存只保留原始安装包；归档每次重新解压，继续保留 Rust 客户端的 DLL/sidecar。保留基本格式检查及下载源回退。
- Windows PowerShell 与 PowerShell 7 的无 OpenSSL 安装回归加入发布 CI；POSIX 回归使用不含 OpenSSL 的隔离 PATH，并实际执行测试客户端。

## 行为与升级说明

安装脚本不再验证下载包或缓存的真实性，请仅使用可信脚本与下载源。客户端/服务端内置自动更新的签名校验不变，Release 仍提供 `.sig` 资产；Windows WinPTY 的内置 SHA-256 固定值检查也保留，它不依赖 OpenSSL。

安装脚本嵌入服务端二进制，需更新提供 `/run.sh`、`/run.ps1` 的服务端才会生效。单独升级客户端不会替换服务端正在提供的旧脚本。Win7/PowerShell 2 的网络及解压兼容路径保留；本轮没有 Win7 实机验收结果。

## 本地验证

- POSIX 无 OpenSSL/无签名场景 9 项行为测试通过，包含 Go/CGO/Rust 启动、离线缓存、sidecar 和无效下载处理。
- PowerShell 7 清空 PATH 的安装回归通过；Windows PowerShell 的运行验证由 Windows CI 执行。
- 服务端嵌入资源构建及 `TestRunner` 定向测试通过。
