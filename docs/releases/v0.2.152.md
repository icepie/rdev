# v0.2.152

- Rust 客户端的发布资产、可执行文件和内部包名统一为 `rs`：`rdev-client-rs-*` / `rdev-client-rs`，不再使用 `rdev-client-gpu-*`。
- `run.sh` / `run.ps1` 的 `--client rs`（PowerShell 为 `-Client rs`）保持入口不变；在新资产尚未发布时会自动回退到 `rdev-client-gpu-*` 旧名，因此旧版本服务端的安装脚本仍可工作。
- 已安装的旧 `rdev-client-gpu` 客户端不会再匹配新资产，需要重新运行安装脚本升级一次。首次安装无需其他变更。
- Rust 客户端自动更新改为查找 `rdev-client-rs-*`；签名校验、归档内容与运行依赖保持不变。
- 仓库目录改为 `clients/rdev-client-rs`，构建目标改为 `make rust-client-rs*`，工作流改为 `rust-client-rs.yml`。
