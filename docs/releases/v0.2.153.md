# v0.2.153

本次为结构重构版本，功能与协议保持不变，目标是降低重复与单文件规模，便于后续维护。

## 服务端与客户端结构

- `internal/server/agent.go` 4019 → 362 行，按会话、线程、文件、回合、设备探测、WebSocket 分层拆分为 7 个文件。
- `internal/server/agent_tools.go` 1551 → 155 行，按 exec/files/edit/search/util 拆分。
- `internal/server/server.go` 2276 → 825 行，拆出传输、会话、发布镜像与 HTTP 视图；`release_assets.go` 并入 `release_download.go`。
- `internal/server/vnc.go` 1225 → 636 行，RFB 编解码独立为 `vnc_protocol.go`。
- `internal/server/agent_history.go` 1094 → 259 行，拆为存储与投影两个文件。
- `internal/client/client.go` 1943 → 419 行，拆出连接、会话、TCP 转发与旧版文件帧。
- `internal/client/desktop_input_linux.go` 960 → 31 行，X11 与 uinput 分别成文件。
- 统一断开清理路径：所有连接关闭都会关闭文件流句柄，修复中断传输后 `*os.File` 泄漏，并补充回归测试。

## Web 界面结构

- 桌面查看器与 Agent 面板共用 `desktop-model`、`desktop-h264`、`desktop-gpu-input`、`desktop-stage-input`、`desktop-gpu-video`、`desktop-shot`、`desktop-clipboard`；`Desktop.tsx` 2953 → 2188，`panel-desktop.tsx` 2460 → 1693。
- 文件页与 Agent 文件面板共用 `file-task-model` 与 `file-transfer-controller`；`Files.tsx` 1985 → 1469，`panel-files.tsx` 1423 → 897。
- `Agent.tsx` 3096 → 2247，线程侧栏与连接生命周期分别独立为组件与 hook。
- 删除未使用的导出、翻译键与重复实现（`Sessions.tsx` 的图像解码改为复用 `lib/terminal-images`）。

## 测试与门禁

- 新增 `desktop-page-smoke`、`agent-page-smoke` 两个页面级渲染测试。
- 新增 `i18n-keys` 守卫：静态翻译键失去调用方时测试失败。
- 新增 RTC 回环双端握手测试，覆盖 file 与 desktop 两条通道。
- 新增客户端断开清理回归测试。
- CI 增加 `gofmt` 检查，格式漂移不再能合并。
- 验证：Go 全量测试、定向 race 测试、Web 112 个文件 / 490 项测试、TypeScript 检查、生产构建通过。

## 行为说明

- 文件传输控制器的合并让两端的少量细节收敛：错误文案统一取 `error.message`、面板磁盘续传携带 `length`、`download_start` 两端都要求 `dir === "download"`、下载结束时统一清理 attempt 记录。
- 桌面 WebCodecs 绘制复用同一画布路径，跳过已由尺寸变化清屏后的重复 `clearRect`。
- 服务端升级会短暂断开连接，客户端自动重连。
