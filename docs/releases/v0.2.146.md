# v0.2.146

本版集中更新设备 ID 管理与安装入口配置。

- 新增管理 API `POST /api/identity/rename`：修改公开设备 ID，持久保存并记录旧/新 ID 审计；在线设备断开后使用原身份凭证以新 ID 重连。
- 重命名拒绝与在线、离线及已撤销身份重复的 ID；持久化失败时保留当前连接和原有内存记录，返回错误。
- Go/Rust 默认使用可跨重启保持的 `rdev-` 短 ID，不再暴露主机名；默认身份读取或保存失败时拒绝启动，不使用临时身份。
- 服务端新增 `--public-server` / `RDEV_PUBLIC_SERVER`，显式指定安装脚本中的客户端连接地址，适用于反向代理与内网部署。

## 升级注意

- 原先依赖默认主机名的 Go/Rust 客户端，若要保留原设备身份与历史，请显式设置 `--id 原主机名` 或 `RDEV_ID`，并保留原身份目录。直接切换到短 ID 会注册为新身份。
- 服务端重命名后，客户端继续使用原本的启动参数和身份目录；不要同时改动客户端 `--id`，否则可能选中另一份身份凭证。
- 管理 API 使用 admin token；未配置 token 时没有 token 保护。建议配置持久数据目录及 admin token，跨不可信网络使用 WSS。
- Go、Rust、Android 发布资产均须附带 Ed25519 签名。安装脚本需要支持 `pkeyutl -verify -rawin` 的可信 OpenSSL 3.0+；Android 仍为 debug APK。
