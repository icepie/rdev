# v0.2.150

## macOS Go 客户端硬件编码

- Go 客户端升级到 `github.com/icepie/go.264 v1.14.2-rdev.1`。macOS amd64/arm64 现在优先使用系统 VideoToolbox 硬件 H.264 编码，硬件不可用时自动回退 CPU。
- VideoToolbox 后端保持 `CGO_ENABLED=0`，不启动 FFmpeg、GStreamer 或外部编码进程；支持码率模式、可用设备上的逐帧 QP、强制 IDR 和 IDR SPS/PPS 恢复。
- Linux 仍按 NVENC、VA-API、CPU 顺序选择；Windows 仍按 Media Foundation、CPU 顺序选择。运行中硬件失败继续禁用该后端并重连到 CPU H.264，CPU 失败才回退 MJPEG。

## 验证

- `go.264` 完整测试、`go264_nohwaccel` 测试及 darwin/amd64、darwin/arm64、windows/386、windows/amd64、windows/arm64、linux/amd64、linux/arm64 构建通过。
- Apple Silicon 真机确认 `videotoolbox` 后端注册、连续多帧 H.264 编码、强制 IDR、SPS/PPS 和 QP 回退测试通过。
- RDev Go 客户端定向测试、macOS 双架构交叉构建及 Linux 服务端生产构建通过。

## 升级

- 服务端升级会短暂断开连接，客户端自动重连。macOS 硬件编码需要升级对应 Go 客户端；GitHub tag 构建发布各平台安装资产。
