# v0.2.148

包含 v0.2.146 的稳定设备 ID/管理重命名及 v0.2.147 的低依赖一键安装修复，并修复 Rust Linux 发布构建阻塞。

- 使用预构建 Linux builder 时显式传入 `RDEV_GPU_INSTALL_DEPS=n`，避免未设置的宿主环境变量覆盖镜像默认值，导致重复安装和意外升级系统依赖。
- 预构建镜像不可用时仍回退到基础镜像并设置 `auto` 安装依赖，不删除任何旧发行版/架构构建目标。
- `run.sh`、`run.ps1` 均无需 OpenSSL，不再下载或校验 `.sig`；基本格式检查和原始包缓存保留。客户端内置自动更新校验不变。

验证：使用本地真实预构建容器、禁用网络，确认 `n` 保留与 `auto` 覆盖两条传参路径；完整各平台构建结果由本版本 CI 验证。安装脚本回归及兼容性边界见 [v0.2.147](v0.2.147.md)。

安装脚本嵌入服务端，更新提供 `/run.sh`、`/run.ps1` 的服务端后修复才会生效。

## 构建镜像补修

- Debian 11/12/13 预构建镜像补齐 `libxkbcommon-dev`，与基础镜像安装脚本保持一致；此前跳过重复安装后暴露了 `cua-driver-sdk` 的 `-lxkbcommon` 链接失败。
- 本地 Debian 12 amd64 预构建容器已执行修正后的依赖安装步骤，并成功编译、链接、运行调用 `xkb_context_new` / `xkb_context_unref` 的程序。其他发行版及 ARM64 由镜像 CI 和发布重跑验证。
- 此项更新 builder 镜像，不移动 `v0.2.148` tag；镜像发布后重跑该版本失败任务。
- Debian 11 的 builder 改用官方 `archive.debian.org` 主仓库及安全归档，解决原安全源索引对应包返回 404 的问题；仅对归档源关闭索引有效期检查，保留仓库签名和包哈希校验。Debian 12/13 源不变。
- Debian 11 本地验证在 Docker Hub 基础镜像下载阶段超时，尚未执行依赖安装；归档源改动的完整安装验证交由原生 amd64/arm64 builder CI，不能将此本地尝试视为通过。

## Rust 系统识别补修（未发布）

- Rust 注册协议补齐显式命名的 `clientOS` 字段，避免默认驼峰序列化生成 `clientOs`；WebSocket 与 TCP/KCP 共用注册消息构造函数。
- 系统信息不依赖桌面功能开关；macOS 使用服务端约定的 `darwin`，避免影响系统图标及 OS 专用命令选择。默认稳定设备 ID、凭据及已注册名称不变。
- 验证：Rust 注册字段回归、默认 ID 持久性测试及客户端编译通过；本地真实客户端分别通过 WebSocket、TCP、KCP 连接服务端，在禁用桌面时 `/api/clients` 均返回 `os=linux`。Windows/macOS 尚未实机验证；现有客户端需更新并重连后生效。
