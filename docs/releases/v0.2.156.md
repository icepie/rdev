# v0.2.156

Agent 队列与错误提示修复。

## 队列错误

- 服务端在 `queue_updated` / `queue_promoted` 的失败回执中新增稳定的 `reason` 代码（`missing`、`steering`、`locked`、`changed`、`too_large`、`empty`、`reordered`、`bad_target`、`finished`），`message` 仍保留英文原文供日志与旧客户端使用。
- Web 界面按 `reason` 显示中文/英文提示；未知代码继续显示服务端原文，不会被吞掉。
- 收到新的队列快照时清除旧的失败提示。此前排队消息被当前回合消费后，界面会停留在「队列 (0)」并持续显示 `Queued message is no longer available.`。

## 验证

- 新增 `thread-sink` 回归：快照到达后清空错误；`reason` 映射到本地化文案；未知 `reason` 回退原文。
- Go 队列相关测试、Web 全量 112 个文件 / 492 项测试、TypeScript 检查与生产构建通过。
